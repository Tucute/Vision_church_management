Now treat the Homepage design as the visual foundation of the entire website.

Analyze every existing page in the repository.

For each page:

- Identify its purpose
- Identify its primary user
- Identify its primary CTA
- Identify the appropriate layout
- Reuse the established Design System
- Reuse existing components
- Reuse typography
- Reuse spacing
- Reuse color tokens
- Reuse interaction patterns

Do NOT create a unique visual style for each page.

Every page must feel like part of the same website.

Create a page-by-page UI architecture:

Page
→ Layout
→ Sections
→ Components
→ Design tokens
→ Responsive behavior
