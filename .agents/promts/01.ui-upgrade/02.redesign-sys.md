Based on the new creative direction, create a complete design system.

The goal is to make every page of the website feel like it belongs to the same church and the same visual identity.

Define:

## COLORS

Create:

- Primary
- Primary dark
- Primary light
- Secondary
- Accent
- Background
- Surface
- Text
- Muted text
- Border
- Success
- Warning
- Error

Do not use too many colors.

The palette should feel warm, calm, trustworthy and suitable for a church website.

## TYPOGRAPHY

Define:

- Display
- H1
- H2
- H3
- H4
- Body
- Small
- Caption
- Navigation
- Button

Define:

- Font family
- Size
- Weight
- Line height
- Letter spacing

Typography must create strong hierarchy.

## SPACING

Create a consistent spacing scale.

## CONTAINERS

Define:

- Maximum width
- Horizontal padding
- Section spacing
- Grid system

## BUTTONS

Define:

- Primary
- Secondary
- Ghost
- Text
- Destructive if necessary

Define all states:

- Default
- Hover
- Active
- Focus
- Disabled

## CARDS

Avoid creating many visually different card styles.

Define a small number of reusable card patterns.

## IMAGES

Define:

- Aspect ratios
- Border radius
- Image treatment
- Overlay usage
- Photography style

## ICONS

Define:

- Icon style
- Size
- Stroke
- Color

## RESPONSIVE DESIGN

Define behavior for:

- Mobile
- Tablet
- Desktop
- Large desktop

## MOTION

Define subtle:

- Hover
- Fade
- Slide
- Page transition

Avoid unnecessary animation.

Create this specification in:

docs/DESIGN_SYSTEM.md

Do not implement the UI yet.
