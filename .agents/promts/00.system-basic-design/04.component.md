Using the existing source code and the new UI Design System, design a reusable component architecture for the website.

Do not implement components yet.

Analyze which components should exist at three levels:

## Level 1 — Primitive components

Examples:

- Button
- Input
- Badge
- Icon
- Typography
- Divider
- Avatar
- Spinner

## Level 2 — Composite components

Examples:

- SearchBar
- UserCard
- ProductCard
- FormField
- NavigationMenu
- Pagination
- Modal
- DataTable

## Level 3 — Page-level components

Examples:

- HeroSection
- DashboardHeader
- ProductGrid
- ProfileSection
- CheckoutSection

For every component specify:

- Component name
- Purpose
- Props
- Variants
- States
- Responsive behavior
- Accessibility requirements
- Where it is currently used
- Whether an existing component can be reused

Avoid creating duplicate components.

Before creating a new component, determine whether an existing component can be extended.

Output a component architecture map.

Do not write implementation code yet.
